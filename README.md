# Ink Evokution — スプラトゥーン3 アップデートの軌跡

『スプラトゥーン3』の全アップデート履歴（Ver.1.1.0 〜 Ver.11.2.0）を、タイムラインとデータビジュアライゼーションで一望できる非公式ファンメイドアーカイブサイト。

## 機能

- **タイムライン年表** — 全41回の更新データを種類（シーズン・大型／バランス調整／不具合修正）でフィルタ可能。前回からの間隔（日数）も表示
- **データビジュアライゼーション** — アプデ間隔の推移、年別の更新回数、更新種類の内訳をChart.jsでグラフ化
- **シーズンの記憶** — 9シーズン＋その後の大型更新をカードで振り返り
- **最新アプデ解説** — Ver.11.2.0のバフ/ナーフとスペシャル必要ポイントの変更一覧
- **次回アプデ予測** — 直近の配信間隔から次回更新日を機械的に推定
- **ブキ種別の軌跡（weapons.html）** — 11ブキ種それぞれの調整履歴。オリジナルSVGピクトグラム付きの図鑑カード、調整回数ランキング、強化/弱体の「調整収支」チャートと年表（メイン性能の調整のみ）
- **メインブキ別の軌跡（mains.html）** — メイン性能が同じブキ（コラボ・ネオ・ヒュー等）を1本に括った約60のメインブキ図鑑。カテゴリフィルタ、調整回数TOP15、ブキごとの調整収支チャートと年表（メイン性能の調整のみ。サブ／スペシャル／必要ポイントはキット固有のため個別ブキの軌跡で扱う）
- **個別ブキの軌跡（kits.html）** — シャープマーカー／ネオ／GECK のようにサブ・スペシャル・スペシャル必要ポイントが異なる個別ブキ約160本を1本ずつ。メイン性能＋サブ＋スペシャル＋スペシャル必要ポイントの強化/弱体をすべて統合した軌跡（出典タグ付き）。レプリカ系・サーモンラン専用調整は除外

## 技術スタック

- 静的HTML / CSS / Vanilla JavaScript（ビルド不要）
- [Chart.js](https://www.chartjs.org/) 4.4.1（CDN）

## ローカルで見る

```sh
# そのままブラウザで開くか
open index.html

# または簡易サーバーで
python3 -m http.server 8000
# → http://localhost:8000
```

## データ出典

- 更新履歴・ブキ調整内容（強化/弱体）: [任天堂サポート「スプラトゥーン3 更新データ」](https://support.nintendo.com/jp/switch/software_support/av5ja/index.html) 全バージョンの公式パッチノートを一次情報として収録（`js/weapons-data.js`・`js/mains-data.js`・`js/kits-data.js`）
- 個別ブキの構成（サブ／スペシャル／必要ポイント／登場時期）と必要ポイント増減: [Leanny/splat3](https://github.com/Leanny/splat3) のゲーム内データ（バージョン別 `WeaponInfoMain.json`）。必要ポイントの増減はバージョン間差分で算出し、公式パッチノートの記述と全件照合済み
- 画像（ブキ・ステージ・ギアパワー）: スプラトゥーン3 ゲーム内アセット（[Leanny/splat3](https://github.com/Leanny/splat3) ミラー経由で取得）。`assets/img/` 配下に、本サイトのID体系に合わせたファイル名で収録
  - `assets/img/weapons/` — メインブキ族 63種（`js/mains-data.js` の id と対応）
  - `assets/img/stages/` — 対戦ステージ 26種（一覧は `js/assets-data.js` の `STAGES`）
  - `assets/img/gearpowers/` — ギアパワー 26種（一覧は `js/assets-data.js` の `GEAR_POWERS`）
